## Ruling body (verbatim)

AXIS 4 — ES-1 scope: RULED. The binding definition:
ES-1 scope = evidence-assembly reads — request-time queries over the raw estate or the qualified-unit corpus to compose an answer, simulation, or brief. Operational-record reads are outside ES-1 — ledger rows, receipts, plans, registry metadata, audit logs read by surfaces whose product is those records.
Dispositions: Findings 2–6 (TraceReceipt, ComplianceProveOneRun, AuditTrail/ChangeARule, CommitReview, Briefs/ConsoleHome): OUTSIDE ES-1 — these read the platform's own operational records, which is their service; a trace page that cannot read the ledger is nothing. Finding 1 (AskConsole → dispatchV2): INSIDE scope, GRANDFATHERED — the synchronous governed pipeline is the current designed S1 answer service, not a latency accident; ES-1 binds new interactive surfaces from now, and Ask's evidence path converts at EAB-3 only against measured latency harm, per ES-4. Land this ruling verbatim as docs/rulings/es1_scope_2026-07-14.md; no code changes ride it.
