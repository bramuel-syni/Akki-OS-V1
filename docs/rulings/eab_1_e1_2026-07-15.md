> Ruling on E1: option (a) — admit the additive locator vocabulary, with the AST cell proving zero contract mutation.
> Rationale for the record: MC-E1 α is the governing precedent — the locator dict absorbed a new modality's addressing without touching five_rings@v0, and occurrence rows are the same shape of problem. {canonical_id, station, timestamp, batch lineage} are locator contents, not contract shape. - **Option (a) ADMITTED.** Additive occurrence-modality locator vocabulary lands as dict-content under `NormalizedUnit.provenance.locator: Dict[str, Any]` (`backend/contracts/five_rings.py:113-119`). Keys: `canonical_id`, `station`, `timestamp`, `batch_lineage`.
- **Zero contract mutation to `backend/contracts/five_rings.py`** and to `backend/tests/invariants/five_rings.contract_snapshot.json`. Parity 31/31 held.
- **AST cell is the load-bearing proof.** Cell asserts class-list, field-list, type-annotation-string, and frozen-flag equivalence between the live contract and its snapshot. **Failure mode = hard `AssertionError` / `raise`.** Not `warnings.warn`. Not `print+continue`. Not `pytest.skip`. Not try/except swallowing. Fails the build on any drift.

## Two execution fences (Owner-verbatim · load-bearing)

- **FENCE 1 · SINGLE CODE PATH IN TRACE RESOLVER.** The trace resolver must parse the new keys (`canonical_id`, `station`, `timestamp`, `batch_lineage`) without special-casing occurrence rows. One code path, or the walkability fold (A2.3) is not real per Owner. Any `if modality == "occurrence"` or `if source_type == "structured"` branch in trace-resolution logic → fence violation.
- **FENCE 2 · AUDIT-WALK CELL END-TO-END COVERAGE.** The audit-walk cell (AC-A2.b) must cover an actual occurrence unit end to end — full trace from occurrence `NormalizedUnit.provenance.locator` back to the canonical audio artifact via the shared resolver. Not a synthetic locator dict. Cell exercises a fixture-B or equivalent real occurrence row that traces to real canonical audio through the production resolver code path.
